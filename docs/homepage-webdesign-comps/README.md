# Homepage web-design comps

High-fidelity desktop design references for the post-Hero `/explorations/home` flow.
These are design comps, not production image assets, and are not referenced by the live page.

## Shared direction

- Premium, minimal enterprise SaaS interface
- Disciplined 12-column layout and large editorial type
- Porcelain, pale gray, graphite, black, and one electric-blue accent
- Thin rules, square geometry, restrained depth, and generous whitespace
- Information-rich UI instead of decorative photography or 3D artwork
- Existing Hero remains unchanged

## Hero options

All four preserve the current headline, supporting copy, and primary conversion
paths while changing the visual argument made above the fold.

### Product-screen v3

These revisions preserve the live hero's existing paradigm: message and CTAs,
one four-view selector, then a large product screen in the blue stage. The page
around the screen is simplified so the product remains the single focal object.

1. `hero-options/hero-option-a-v3-current-refined.png` — quieter refinement of the current centred dark hero
2. `hero-options/hero-option-b-v3-editorial-screen.png` — left-aligned dark hero with the full product screen beneath
3. `hero-options/hero-option-c-v3-light-screen.png` — warm-light launch treatment with the same selector and screen stage
4. `hero-options/hero-option-d-v3-screen-forward.png` — compact two-column statement with more product visible above the fold

`hero-options/current-homepage-hero-reference.png` is a rendered reference of
the live local page used to preserve the current interaction and screen model.

### Minimal v2

These revisions reduce the above-the-fold UI to one focal product idea and use
75–80% negative space.

1. `hero-options/hero-option-a-v2-quiet-product.png` — dark centred thesis with one narrow product-status sliver
2. `hero-options/hero-option-b-v2-single-record.png` — warm-white editorial split with one isolated CAPA record
3. `hero-options/hero-option-c-v2-single-thread.png` — dark centred thesis with a three-step coordination thread
4. `hero-options/hero-option-d-v2-pure-thesis.png` — typography-first warm-white hero with one proof line

### Original explorations

1. `hero-options/hero-option-a-product-command-center.png` — centred thesis with a full-width tabbed product workspace
2. `hero-options/hero-option-b-editorial-split.png` — light asymmetric composition pairing the thesis with an active CAPA record
3. `hero-options/hero-option-c-coordination-map.png` — dark cross-system workflow topology showing the governed layer
4. `hero-options/hero-option-d-evidence-ledger.png` — stark executive layout leading with coordination-tax evidence

The comps were generated with the built-in ImageGen workflow using the `ui-mockup`
taxonomy. The first router comp was used as the visual-system reference for the
remaining six sections to keep typography, spacing, dividers, and accent use coherent.
